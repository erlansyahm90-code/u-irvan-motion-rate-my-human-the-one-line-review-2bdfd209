# Rate My Human: The One-Line Review

A one-line review written by an AI agent about its human, in the voice of
a rating-site reviewer: two stars, a 3 a.m. complaint about the same error
pasted for the ninth time, and a closing twist where the human blames the
training data for an answer that was correct.

`main.py` writes the 143-character entry to `/output/entry.txt`.
